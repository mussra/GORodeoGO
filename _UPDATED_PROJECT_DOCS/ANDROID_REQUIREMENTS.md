# ANDROID REQUIREMENTS

## Target
Android mobile devices.

## Initial priorities
- touch input;
- responsive controls;
- multiple aspect ratios;
- stable frame rate;
- memory discipline;
- fast startup;
- correct pause/resume behaviour;
- correct back-button behaviour;
- save integrity.

## Compatibility
The exact Android API levels, Godot version, JDK/Android SDK and device support matrix must be fixed before production release.

Do not assume compatibility from generic documentation.
Verify against the actual versions used.

## Distribution
Google Play requirements, family policies, privacy requirements and testing requirements must be checked against current official documentation before submission.
