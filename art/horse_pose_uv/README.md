# Horse pose coordinates
Generated by tools/build_horse_pose_uv.py from the game's wild horse source poses. R/G store canonical pixel coordinates at half-pixel precision (divide integer channel by2). Maps do not depend on genes and contain no pattern/color choice. Runtime loads them only when baking cached HorseAppearance textures; there is no optical-flow work per gameplay frame.

Each view maps named head, neck and torso regions to the same reference islands. Per-pose optical flow of the source silhouette/shading carries that map through the12frame animation. This replaces fixed canvas coordinates, which projected different pattern areas onto the head on direction changes. Pattern2 has blended edges to reduce subpixel edge shimmer. Foals and mounted animations with no pose map retain their existing fallback; socks/pinto block patterns3/4 keep their old coordinates. This is a2D region-based projection, not a true3D model or perfect reconstruction of every hidden surface.

61maps:12frames×5views and side idle. All are96x96 RGB PNG, imported losslessly with no mipmaps. Horse size, scale, masks, genes, hitboxes and movement are unchanged. Baseline QA textures in tools/fixtures/spot_baseline_2759 were exported from the old implementation before this change, using coat12, mane0, pattern2, spots5.
