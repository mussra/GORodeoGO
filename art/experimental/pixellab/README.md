# PixelLab trial, 2.7.61

Source: sheets supplied by Antonio via the experiment requested9Nov2026, horse/rider PixelLab PixiMiniMax trial. Nine96×96frames, extracted row-major from transparent3×3sheets enlarged3×. No AI generations or payments in this integration. Source-output ownership/licensing was researched separately; not independently rechecked in this code change.

Experimental, default ON in this test APK. Main menu > Settings > PixelLab experimental toggles it for the next gameplay scene, stored separately from game saves. Shared PixelLabTrial applicator used by wild horses and both player modes.

Only lateral walking and right-facing rest are replaced. Left mirrors right. Other directions, jumping, stunned animations, portraits, masks and genes are retained. Thus colors/details can change at direction/state transitions. Fixed coats are a visual trial, not the saved genotype. Nine frames at9fps preserves the approximately1-second comparison cycle. Original sprites remain intact, disable the setting to restore them.

Known source-art faults: some crossed/duplicated legs, changing mane/tail silhouette. No production-quality guarantee and no newly generated directional views.
