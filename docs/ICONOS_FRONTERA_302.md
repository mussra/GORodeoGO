# Iconos de Frontera

Cinco destinos para una hoja uniforme. Libro y Corona ya tienen piezas reutilizables. Misión, DEBUG y Rendimiento necesitan ilustraciones específicas; sus piezas actuales son temporales, de hojas anteriores de Ant.

| Destino | Pieza que se usa ahora | Pieza propuesta |
|---|---|---|
| Libro de crianza | Portada de libro existente | Libro con emblema de caballo |
| Coronas y victorias | Corona dorada existente | Corona dorada |
| Misión | Admiración dorada existente | Pergamino con marca |
| DEBUG | Cuadrícula dorada existente | Caja con llave inglesa |
| Rendimiento | Gráfico ascendente existente | Indicador de esfera y aguja |

## Prompt para generar la hoja

Genera UNA SOLA hoja PNG de cinco iconos para el juego móvil Rancho, ilustración2.5D western acogedora, cuero caramelo, madera cálida, oro suave, azul petróleo, contornos nítidos y volumen pintado a mano, mismo estilo que los iconos de equipo de referencia. Lienzo2400x1600, cuadrícula exacta3columnas por2filas, celdas800x800. Orden izquierda a derecha: fila1 libro de crianza cerrado con emblema de caballo; corona dorada de victorias; pergamino de misión con una marca de verificación. Fila2 caja de herramientas de diseño con llave inglesa, para DEBUG; pequeño indicador de rendimiento con esfera y aguja; última celda vacía y transparente. Un objeto compacto por celda, centrado, reconocible a64px, margen transparente mínimo15% dentro de cada celda. Transparencia real, sin fondo de tablero, sin suelo ni sombra exterior. Ningún elemento cruza una celda. Sin personas, animales completos, texto, letras, números, logos, botones, marcos ni marcas de agua. No recortes ninguna parte.
