# Rancho Prueba 3.0.3

VersionCode463. Misma aplicación y firma de prueba, instalable encima de3.0.2.

## Incluye
Los cinco iconos de la hoja nueva de Ant sustituyen las piezas temporales en los accesos de Frontera: libro de crianza, coronas, misión, herramientas DEBUG y rendimiento. Se mantienen posición y área táctil de cada tarjeta, textos y acciones.

La hoja1536x1024 tiene alfa real, no un fondo negro. No se elimina fondo. El recorte ignora píxeles casi transparentes alejados al calcular el contorno visible; conserva los píxeles y alfa del original dentro del contorno con4px de margen. Cada figura se ajusta a224px dentro de una pieza transparente de256x256, sin estirarla ni cortar partes. Original conservado, excluido del APK; script de recorte reproducible incluido.

No cambia el contenido del libro, las coronas de logros, otras ilustraciones, audio, reglas, economía ni guardado. La caja identifica el acceso a herramientas DEBUG; no sustituye los iconos de cada herramienta individual.
